See what is really in a code base. In one command.

Sokrates turns any git repository into a set of self-contained HTML reports: size and structure, duplication and complexity, components and dependencies, who works on what, and how all of it changes over time. Any language, no setup, free and open source.

cd <your-project> docker run --rm -v "$(pwd):/code" ghcr.io/zeljkoobrenovic/sokrates analyze open _sokrates/reports/index.html

No Docker? Run the JAR with Java 17+  ·  Step-by-step guide  ·  Live examples

The overview of a report — OpenAI Codex, live ↗

What you get

Size & structure
Lines of code per scope, language and folder; file sizes, age and freshness; zoomable maps of the whole tree.
Duplication & complexity
Duplicated blocks across files and components; unit size and conditional complexity, with the risky code listed.
Components & dependencies
Logical decompositions you define in one JSON file, with dependency graphs between components and files that change together.
People & teams
Who contributes where and how much, knowledge concentration, team topologies, bots and AI co-authored commits.
Trends
Commits, churn and contributors per year, month, week and day; what is active, what is legacy.
Landscapes & AI insights
Aggregate many repositories, or whole GitHub and GitLab organizations, into portfolio views. Let an AI coding agent refine the analysis and explain it.

The Features tab describes every report; the Landscapes and AI insights tabs cover the last two.

Why Sokrates

  • Show the code, skip the interviews. A pragmatic, inexpensive way to get rich facts about any software system: the analysis runs on the source and the git history, nothing else is needed.
  • Polyglot by design. Forty-plus languages out of the box; everything else still gets size, duplication and history reports. It borrows from code spelunking and grep: structure on top of regex searches, instead of per-language parsers.
  • Reports you can hand over. Static HTML that opens from disk or any web server, no database, no service to run.
  • Scales from one repo to an organization. The same reports aggregate into landscapes with sub-landscapes, team views and trends.
  • Open source, MIT. Built by Željko Obrenović as one of the tools behind Grounded Architecture and its lightweight architectural analytics.
